# WebSocket-события

Сервер: `WSController` (`src/ws_controller.h`), порт 81.
Каждое сообщение — текстовый JSON-объект:

```json
{"event": "<название>", "data": <структура зависит от события>}
```

> При добавлении новых событий или изменении существующих — обновлять этот файл.

Типы полей: `id` — число (id websocket-соединения), `name` — строка (сейчас `"player" + id`).

## Список событий

| Название | Направление | Кому | data | Описание |
|---|---|---|---|---|
| `setId` | сервер → клиент | подключившемуся | число | Собственный id клиента. Первое сообщение при подключении. |
| `setOnlineUsers` | сервер → клиент | подключившемуся | массив объектов | Все онлайн-пользователи на момент подключения (включая самого клиента). |
| `addOnlineUser` | сервер → клиент | всем, кроме нового | объект | Подключился новый пользователь. |
| `removeOnlineUser` | сервер → клиент | всем | число | Пользователь отключился (`data` = его id). |
| `gameStarted` | сервер → клиент | участникам | объект | Игра началась. `data` повторяет `startGame`. |
| `setGameState` | сервер → клиент | участникам | объект | Полное состояние игры (при старте и далее при изменениях). |
| `cardPlayed` | сервер → клиент | участникам | объект | Карта применена к кубиту. Вслед за ним приходит `setGameState`. |
| `gameEnded` | сервер → клиент | участникам | объект | Регистр игрока совпал с целевым, игра окончена. |
| `cardScanned` | сервер → клиент | всем | объект | Считана карта вне игры. |

## Структуры data

### `setId`

```json
3
```

### `setOnlineUsers`

```json
[
  {"id": 0, "name": "player0"},
  {"id": 3, "name": "player3"}
]
```

### `addOnlineUser`

```json
{"id": 4, "name": "player4"}
```

### `removeOnlineUser`

```json
4
```

### `gameStarted`

```json
{"players": [0, 3], "cubitCount": 5}
```

### `setGameState`

Грани кубиков — строки `"+"`, `"-"`, `"i"`, `"-i"`, `"0"`, `"1"`.
`registers` — регистри игроков в порядке списка `players`.
`currentPlayer` — индекс текущего игрока, `playedCards` — карт сыграно
текущим игроком в этом ходу (после второй карты ход переходит следующему,
и приходящее состояние уже содержит нового текущего игрока и 0).
`cardsOnField` — карты, лежащие на кубитах: объекты с полями `player`
(номер игрока), `cubit` (номер кубита) и `card` (название типа). Пока ни
один тип карты не остаётся на поле — массив пуст.

```json
{
  "players": [0, 3],
  "registers": [["+", "i", "1"], ["0", "-", "i"]],
  "targetRegister": ["1", "0", "+"],
  "currentPlayer": 0,
  "playedCards": 0,
  "cardsOnField": [{"player": 1, "cubit": 2, "card": "pauli_x"}]
}
```

### `cardPlayed`

`target.register` — номер игрока, на чей регистр применена карта, `target.cubit` —
номер кубита, `card` — название карты (`pauli_x`, `pauli_y`, `pauli_z`,
`pauli_x3`, `pauli_y3`, `pauli_z3`). Для карт на три кубита `cubit` — начало окна.

```json
{"target": {"register": 1, "cubit": 2}, "card": "pauli_x3"}
```

### `gameEnded`

`winnerId` — id победившего игрока (тот же id, что в списках пользователей),
`winnerName` — его имя (`"player" + id`).

```json
{"winnerId": 3, "winnerName": "player3"}
```

### `cardScanned`

Приходит при считывании любой метки, пока игра не идёт и не ожидается карта
для записи (`writeCard`). `registered` — есть ли метка в реестре; `type` —
название типа карты, только если `registered` истинно.

```json
{"registered": true, "type": "pauli_x"}
```

```json
{"registered": false}
```

## Клиент → сервер

Формат тот же: `{"event": "...", "data": ...}`. Сервер парсирует JSON при получении и
передаёт `data` подписчикам (`WSController::on(event, handler)`). Сообщение без
строчного поля `event` или с битым JSON отбрасывается.

| Название | data | Описание |
|---|---|---|
| `startGame` | объект | Начать новую игру. Обрабатывается, только если игра не идёт. |
| `selectTarget` | объект | Выбор кубита для следующей карты. Обрабатывается, только если отправитель — текущий игрок. |
| `writeCard` | строка | Ожидать карту для записи в реестр. `data` — название типа карты. |
| `giveUp` | — | Сдаться. Только участник во время игры; побеждает другой игрок (`gameEnded`). |

### `startGame`

`players` — id пользователей-участников, `cubitCount` — число кубиков в регистрах.

```json
{"players": [0, 3], "cubitCount": 5}
```

### `selectTarget`

`player` — номер игрока в игре (индекс в списке `players` события `startGame`),
`cubit` — номер кубита в его регистре. Можно выбирать как свои, так и чужие
кубиты. Выбор можно менять до считывания карты.

```json
{"player": 1, "cubit": 2}
```

### `writeCard`

`data` — строка, название типа карты (`pauli_x`, `pauli_y`, `pauli_z`,
`pauli_x3`, `pauli_y3`, `pauli_z3`). Помечает контроллер: следующая метка,
считанная вне игры, регистрируется в реестре за этим типом и сохраняется в
память контроллера. Метка с другим типом перезаписывается на новый.

```json
"pauli_y"
```

### `giveUp`

`data` не используется. Отправитель сдаётся: игра заканчивается, всем
участникам приходит `gameEnded`. Победитель — следующий за сдавшимся
участник по кругу (при двух игроках — другой). Вне игры или от
не-участника игнорируется.

```json
null
```
